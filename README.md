# Select Game Store — ملفات الموقع

## طريقة الرفع (مرة واحدة)
1. افتح المستودع على GitHub ← **Add file** ← **Upload files**.
2. اسحب **كل** محتويات هذا المجلد (بعد فك الضغط): `index.html` و `store-data.json` و `.nojekyll` و مجلد **img** بالكامل.
   - لازم `img` يكون في نفس مستوى `index.html` (مش جوه مجلد تاني).
   - لو الملف `.nojekyll` مش ظاهر عندك، مش مشكلة، تقدر تتخطاه.
3. اضغط **Commit changes** واستنى لحد ما الرفع يخلص.
4. **Settings ← Pages ← Deploy from a branch ← main / (root) ← Save**.
5. بعد دقيقة افتح لينك الموقع (Ctrl+Shift+R لو شفت نسخة قديمة).

## بعد كده
ادخل الموقع كأدمن ← اضغط **Publish** (أو Live setup) ← الصق الـ Token فقط واضغط **Connect** (الموقع بيعرف اسم المستودع لوحده). من بعدها: عدّل أي حاجة واضغط **Publish** وهيظهر للعملاء بعد حوالي دقيقة، والموقع بيقولك "ظهر للعملاء ✓" لما يتأكد.

## للتأكد إن الصور اترفعت
افتح: `لينك-موقعك/img/` — لازم تلاقي الصور. لو ظهر 404 يبقى مجلد img ماترفعش.
